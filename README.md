# Navio-miniapp

Navio 小程序开发工作区，汇总已下载的芋道相关源码和资源。

| 目录 | 内容 |
|---|---|
| `ruoyi-vue-pro/` | Java 后端；当前已启用会员、支付、商品、营销、交易和统计模块 |
| `yudao-mall-uniapp/` | uni-app / Vue 3 小程序前端 |
| `yudao-ui-admin-vue3/` | Vue 3 管理后台 |
| `yudao-demo/` | 此前稀疏下载的商城静态资源 `yudao-static/mall/` 及仓库根元数据 |

## 来源与范围

这是当前工作区的源码快照。四个子项目直接存放真实文件，不使用子模块；上游 Git 历史未合并。
各项目的上游地址、固定提交和下载范围见 [SOURCE_PROVENANCE.json](SOURCE_PROVENANCE.json)。各目录保留自己的 LICENSE，根说明不替代子项目许可证。

`yudao-demo` 按此前已下载的范围保留，未下载的 SSO 示例和其他预编译后台不在此快照中。

## 本地开发

- HBuilderX 打开 `yudao-mall-uniapp/` 源码根目录运行。
- 微信开发者工具导入 HBuilderX 生成的 `yudao-mall-uniapp/unpackage/dist/dev/mp-weixin/`，该目录为编译输出，不在版本库中。
- 已准备的本地后端辅助源码位于 `ruoyi-vue-pro/.local-dev/`，包括服务管理、独立配置、表结构生成、本地演示数据和原创占位素材。
- 根目录提供 macOS 的启动/停止脚本。脚本依赖项目专属运行环境；Java 17、Maven、MySQL 8.4、Redis 7.4 安装包和数据目录不上传。
- 开发接口为 `http://127.0.0.1:48080/app-api`，本地演示租户编号为 `1`。MySQL 为 `127.0.0.1:13306`，Redis 为 `127.0.0.1:16379`，原创素材服务为 `127.0.0.1:48081`。
- 实际 `.env` 和敏感配置值没有上传。首次恢复时，按相邻 `.example` 模板创建自己的环境文件；按 YAML 中的环境变量提供配置。运行密码由本地管理脚本生成，保存在忽略的本地文件中。

本地数据库是根据公开实体生成的开发结构，含明确标注的演示数据，未使用官方受限商城 SQL。没有附带真实商品报价、会员资料、支付密钥或供应商凭证。展示接口基线已在原工作区验证；真实微信登录、支付与履约另行配置和联调。

## 版本管理

已保留当前源码改动及本地开发辅助源码。依赖、数据库、日志、PID、缓存、编译输出和真实环境文件由忽略规则排除。后续业务开发可直接在相应子目录进行。

原上游 AI / IoT 集成测试中的字面量凭证已在此快照改为 `NAVIO_TEST_*` 环境变量；运行这些集成测试前自行配置。原始运行工作区未被修改。
